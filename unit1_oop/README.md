The main design goals of OOP are robustness, adaptability, and reusability. A robust program is one that can handle unexpected inputs without failing. This is extremely necessary for life-critical applications, ie. applications needed for emergencies or anything that could lead to someone dying. An adaptable program is one that evolves over time to keep up with changes.This kind of program is also portable, meaning it can run with minimal change even on different hardware and operating systems.
